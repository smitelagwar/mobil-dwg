## Findings and fixes during V06

Two validation-infrastructure defects were found before the authoritative PASS. Neither final finding was classified as a production safe-open/parser failure.

1. Historical `Stage06.OpenFlowProbe` targeted `net10.0` and still referenced `MobilDwg.App` after the app became Android-only `net10.0-android36.0`. Restore therefore failed with `NU1201` before the historical safe-open regression could execute. The probe was decoupled from the Android app project and now links the same production BCL safe-open sources while retaining the production Cad/Core references. The app was not made multi-target merely for the host probe.
2. The first real DocumentsUI automation opened FilePicker correctly but remained on `Recent / No items`. The test looked for `Downloads` before opening the roots navigation drawer. Failure artifact UI XML showed the `Show roots` control. The harness was hardened to open roots, choose `Downloads`, then choose the target file. Production FilePicker code was not changed to hide the failure.
