## Scope

V02 revalidates dependency pinning, locked restore, resolved NuGet graph, package license/hash evidence, vulnerability status, production `src/` dependency boundaries, and the Android native-asset boundary. It does not validate the real `MobilDwg.App` APK, DWG/DXF fidelity, UI/lifecycle behavior, physical Android devices, or iOS.

No emulator run is required for V02 because the repository still has no real installable `MobilDwg.App` Android application; that conversion belongs to V04. Running the temporary Stage01Smoke emulator gate would add no V02 packaging evidence.

## Finding and correction

The historical Stage 02 evidence described direct NuGet packages as exact-pinned, but Central Package Management used plain versions such as `Version="3.7.1"`. The committed lockfile therefore recorded the direct request as `[3.7.1, )`, which is not the strict exact-range representation required by the project policy.

V02 corrected this mismatch:

- `ACadSharp` -> `[3.7.1]`
- `SkiaSharp` -> `[4.151.1]`
- test/fallback-only `IxMilia.Dxf` -> `[0.8.4]`

The lockfile now records exact requested ranges `[3.7.1]` and `[4.151.1]`, and the audit fails if an open/floating/direct range reappears.
