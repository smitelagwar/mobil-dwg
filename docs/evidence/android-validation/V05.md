## Findings and fixes during V05

Two validation-gate portability defects were found before the authoritative PASS. Neither was a parser/product failure:

1. Historical `stage05-parser-spike.sh` used `/warnaserror`. Windows Git Bash/MSYS rewrote it as `C:/Program Files/Git/warnaserror`, causing MSBuild to reject the command line before parser validation. The switch was changed to portable `-warnaserror`.
2. The historical package gate parsed localized `dotnet list package` text with a grep pattern that did not accept the exact-range display `[3.7.1]`. The mini-corpus had already passed, but the localized output caused a false-negative. The final gate preserves the human-readable package graph as evidence and validates ACadSharp deterministically from `Directory.Packages.props`, `packages.lock.json`, and `project.assets.json` instead of localized CLI prose.
