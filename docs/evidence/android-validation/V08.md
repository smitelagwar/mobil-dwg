## Gate hardening during V08

The first real V08 run exposed one validation-harness false positive, not an Android production-graph failure.

The original gate scanned the entire raw `project.assets.json` text. The `libraries[*].files` inventory for the cross-platform `Microsoft.Maui.Controls` NuGet package legitimately lists files shipped inside that NuGet package for multiple platforms, including paths such as `lib/net10.0-ios26.0/...`. Those package-file inventory entries are not resolved Android targets or dependencies.

The gate was corrected to inspect only the actual resolved target graph, project framework names and resolved library identities. It does not treat unused files physically present inside a cross-platform NuGet archive as Android dependency resolution.
